# Study Registry

This directory contains documented design studies, A/B tests, ablation studies,
and other empirical investigations for AgentScaffold.

## Creating a New Study

1. Copy the template: `docs/ai/templates/study_template.md`
2. Name the file: `STU-YYYY-MM-DD-short-description.md`
3. Fill in the YAML front matter metadata
4. Document methodology and findings
